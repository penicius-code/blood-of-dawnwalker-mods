# Standing Planeshift

This mod lives in its own repository: **[dawnwalker-standing-planeshift](https://github.com/penicius-code/dawnwalker-standing-planeshift)**.

Coen stands upright on walls during Shadowstep instead of crouching, and a vanilla bug that leaves the wolf stuck after wolf Haste plus Shadowstep is repaired. Single-player only.

| | |
|---|---|
| Requires | UE4SS for Dawnwalker; Mod Setting Menu optional |
| Latest version | 1.0.3 |
| Status | tested in game on 2026-09-30, released |

Published on Nexus Mods as "Wallwalker - Standing Planeshift": <https://www.nexusmods.com/thebloodofdawnwalker/mods/676>

There is no code in this folder. Install, uninstall, compatibility and known issues are in the [standalone README](https://github.com/penicius-code/dawnwalker-standing-planeshift#readme). The research probe [Wolf Probe](../../research/wolf-probe/README.md) in this repository found the cause of the stuck wolf that version 1.0.3 repairs.
